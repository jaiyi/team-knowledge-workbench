# P1 及后续：纵向切片工程设计与待实施任务草案

> 本文件把[现行产品逐页设计](../产品/界面功能设计/README.md)与[方案 08 的唯一实施/验收路线](../方案/08-MVP实施、验证与验收.md)拆为可独立演示的工程任务草案；具体 API、授权/事件与增改退役/三方对账字段以[方案 11 的拟议集成基线](../方案/11-开发工程设计与集成基线.md)为输入，经方案阶段 1 的设计冻结和目标 Spike 后实施。[方案 12 的 R-01–R-09/I-01–I-04](../方案/12-未决工程风险与决策记录.md)仍是产品已裁决、工程待证；这里的任务完成条件不是已有通过证据。任务尚未发布到 tracker。

## 1. 实施编号、事实与门禁

| 本工程阶段 | 方案阶段 | 能力节点（独立验收，不按编号推导完成） | 可演示边界 |
|---|---|---|---|
| P0：既有基础与安装/Provider Spike | 0–2；部分 3 的骨架 | N0 安装子项待证 | 当前 `p0_overall: no_go`、仅 `p0_transition: allowed_with_no_go`；以[03 当前状态](./03-P0当前状态描述.md)为准，不能用本地健康或 HTML 演示解除门禁 |
| P1：隔离 fake contract | 1–3；并行做 2 的 Spike | N0 基础、N1 契约预备 | 私有对象/权限语义与假 Provider 的完整最小操作，无真实团队资产写入 |
| P2：持久控制面与真实写入准入 | 3–4 | N1；N0 安装仍单独验收 | 两个 asset-space 身份、持久 Worker、撤权、恢复和对账负向验证通过后，才允许**受控非生产**真实团队写入 |
| P3：Knowledge-first | 5；阶段 6 的 Knowledge 部分可随后先行 | N2；N4 的 Knowledge 子项 | 材料/来源→AI 辅助待核提炼→正式审核→Git/WeKnora 读回；合成输入经真实非生产链进入大盘，项目 Wiki 授权阅读与真实 AI 巡检另验 |
| P4：Skill MVP | 7，复用阶段 6 的事件契约 | N3；N4 的 Skill 子项 | 未批准 Draft 先过静态检查，获隔离 Runner 准入后用目标模型实际试跑与人工语义评测；受审 Git 发布、固定包与最小消费分开 |
| P5：消费、反馈与 Tool Demo | 6，可在 P3 后先做 Knowledge，P4 后补 Skill | N4 整体需双资产和真实只读 Tool Demo | 无会话反馈、受控任务/Trace 引用、可信底账与三层结果；真实场景的知识效果须另验 |
| P6：选型后的 Provider 与试点 | 8–9 | N5–N6 | 至少一台获准测试设备验证 TeamAI 固定包；独立 Registry 需求成立才选 SkillHub；逐目标装载、主动复盘 Skill 与业务试点另验 |
| P7：按需演进 | 9 后另行决策 | 无自动新增节点 | 不把 User-authored Plugin、生产数据或模型治理纳入本批任务 |

这里的 P1–P6 是[工程路线](./00-整体工程开发阶段划分.md)的较细实施切片；[方案 11](../方案/11-开发工程设计与集成基线.md)称「P1 双资产 MVP」是更粗的交付集合，不能把同名数字当同一阶段。阶段 0 的低风险试点场景、受益者、人工基线、业务结果 Owner 和停止条件尚须业务侧确认；合成 fixture 的技术实验不以此为前置，但 Pilot Beta 必须有这些输入。真实团队资产写入前，可信服务端身份/ACL、双空间隔离、撤权、Worker 重启恢复、路径/secret 负向测试和 reconciliation 必须全部通过；没有任何单项 fake 通过可替代整体门禁。

每张任务沿「用户动作／获准服务身份→服务端校验/状态→对应 Provider 或 fake→可返回的 UI/结果/失败→自动测试与证据」给出一个最短完整路径。表中 `Blocked by` 只列**本表的真前置**；`外部门` 属于额外的环境/安全/业务硬条件，不能当已完成任务。并行开发不能绕过前置验收。各项演示使用脱敏合成样本；未获真实非生产授权时只交付明确标注的隔离 fake/contract 结果，不将目标任务勾为真实通过。具体字段不在本文件再造第二套状态字典。

## 2. 已确认方向的待实施 tracer-bullet 任务（不发布）

**T01｜五入口状态与按需会话（P1/N0 契约）**　**Blocked by：无。** 从本地隔离身份打开五个入口，有权的默认「我的工作台」及每入口 `disabled_reason/provider_status` 可读；只读浏览/复用已有准确版不产生会话或团队候选，明确正式创作经当前身份、来源、空间和动作校验后才返回唯一 `session_id/draft_id`；可选团队候选受理另见 T27，不由本票的导航触发。验收：同一操作的重复点击幂等；跨空间/撤权/旧基线拒绝且无 Session/Draft；DSH 原生对话不成为第六入口，静态页面不被称真实后端；首页真实个人待办索引后移，不以原型假待办验收。真实主体集成仍受 T07 门禁。

**T02｜个人 Inbox 私有保存与零副作用（P1/N1 契约）**　**Blocked by：无。** 用户保存、回访、删除获准的最小链接定位/笔记；独立 PG 私有记录可刷新读回，本人同/异空间按权限读取。验收：第二主体/猜 ID/撤权/过期引用拒绝；保存、回访、导航到知识页和删除都没有 HTTP 抓取/解析、团队候选受理、反馈、Session、Git 或索引操作；不复制受限原文、签名 URL 不泄露。目的页另经明示授权的 T27 受理不是 Inbox 保存副作用，`inbox_item_id` 不充当 `submission_id`。真实用户持久化启用受 T07 与 I-01 门禁；否则只用隔离 fixture。

**T03｜从个人 Inbox 导航至可选受理或正式创作（P1/N1 契约）**　**Blocked by：T02、T01。** Inbox 只是本人待处理备忘；成员主动选定位进入知识/Skill 入口时先展示待核来源，只读导航不抓取、不提交候选、不建会话。若另选具体内容、来源、分享范围和团队目标，按 T27 独立授权受理并返回 `submission_id`；也允许跳过受理直接决定正式知识/Skill 新建或指定版修订。正式创作须重新核当前身份、来源可见性/分享用途、空间、既有资产准确基线与动作权限，才创建不同的唯一 `session_id/draft_id`；受理回执不继承创作权限，进入创作也不等于全团队可用。验收：导航、取消、无权来源、失效引用、跨空间、旧基线或撤权均不建会话、不复制正文、不写未经授权的团队对象；重复明确创作请求幂等；个人项删除只影响私有备忘，另获准的候选或正式资产按自身权限和状态管理。真实主体启用受 T07 门禁；独立 Feedback Candidate 的受理不是团队内容候选。

**T04｜无会话疑点、反馈与受控任务引用（P1→P5/N4 Knowledge 子项）**　**Blocked by：无。** 用户无消费事件或正式资产也能报最小疑点并取得独立 Feedback Candidate 状态回执（不复用 T27 的 `submission_id`）；若来自 DSH 对话疑点或实际调用，保存可失效的任务/Trace 引用及有证据的知识引用版、Skill 加载/执行版，让获权受理人在原任务按当前身份/空间重验后核对，再分流为知识修订、Skill 回归、Provider 或平台问题并回访。验收：报告、拒绝、误报关闭、转交均零自动 Session/正式资产变更；主动复盘与反馈共享最小受控引用，不复制完整 Session、Prompt、Tool 参数或原始 Trace；缺可信宿主事件可报疑点而不声称本次调用已核实；失效、撤权、跨空间、重复提交和非知识根因均可见拒绝或处理人/下次检查时间。仅明确修订并经 T01 重鉴权后关联唯一新会话；真实空间启用受 T07，原任务深链/事件能力另须目标实测。

**T05｜材料覆盖、锚点与时效阻断（P1→P3/N2）**　**Blocked by：无。** 用材料/知识 owner 冻结的首期格式×大小×语言/版式、关键区块和形成/生效/截止规则，从固定脱敏原件/hash 生成逐页/段/表行或单元格锚点、已读/未读/排除范围和只读待核结果。验收：逐区块原件对照；原文件的表头、原列名及五行 KPI 列关系确能核实时，以同一局部表格及实际行号保留，KPI 只作为报告期待核主张，不拆成五篇知识或标为当前已核指标；结构无法确认时标待核，不补造列值。损坏、截断、漏页/表/附件、关键锚点缺失、时效不明、未支持的扫描/复杂表格不产生可送审正式候选；获准补证后按固定版本重验，不拿模型置信度补漏。真实上传/解析范围须由目标 parser 正负例和 owner 批准，缺证仅做隔离测试。

**T06｜受限链接抓取与原件定位（P1→P3/N2）**　**Blocked by：T05。** 与 T02 无前置关系； 知识入口由用户明确选用新闻网页、普通网页或 Git 仓库 README/落地页链接，当前主体、来源/用途/空间再授权后才临时抓固定原件、解析并提供来源锚点；Inbox 操作不进入本路径，飞书等需登录来源后移。验收：允许列表、每跳跳转/DNS/实际连接目标、文件大小/MIME/内容、解析器隔离/超时的正负例；跨空间、私网/内部地址、恶意/损坏输入拒绝且零外传；只读梳理不自动分享、建会话或留全文。目标来源/安全准入未通过即仅保留最小待核定位；历史来源原文优先经授权的指定 WeKnora 来源文档深链或原系统定位，不伪造全文阅读器；项目 Wiki 的获权内读另见 T23。

**T07｜可信身份、双空间与连接准入（P2/N1）**　**Blocked by：T01。** P0 安装门不因本任务自动通过； 管理员按团队 asset-space 在服务端绑定 Git、WeKnora（可选具体 workspace/知识库空间）等资源；PG 与共享凭据由平台集中管理，成员安装同一 Workbench 不逐台填写。服务端以目标 DSH 身份交换重核成员/角色、空间与资源绑定；获权管理员能草拟、检查、激活或停用连接，成员只见非敏感状态。验收：两个空间与两台独立 Desktop 的会话/草稿/Inbox/审计隔离，篡改 team/目标/路径、符号链接逃逸、共享凭据、撤权后的旧 session/job/callback 均拒绝；连接检查不是资产已发布，Secret Manager 引用不回显，配置版本冲突/旧配置在途操作有读回。**外部门**：固定目标 DSH 身份与签名/撤权实测、目标凭据/Owner 授权、双空间负向报告；未通过仍不得真实写入。

**T08｜持久操作、Worker 与半成功对账（P2/N1）**　**Blocked by：无。** 可用脱敏 fake 开发，真实写入须 T07； 用户能提交一个受限 fake 操作并在重启 API/Worker 后查询同一 operation 的结果、失败/unknown/人工接管；outbox 与状态同事务，lease/fencing、重试、CAS 和审计可复现。验收：响应丢失、重复/乱序/旧 callback、超时、read-back mismatch、lease 争夺、Worker/PG 恢复不丢任务、不重复外部副作用或把半成功显示绿色；secret/path 负向、两空间 job/outbox 隔离和数据恢复证据齐全。T07 与 T08 **连同外部能力准入**均通过才解除受控真实团队写入阻断。

**T09｜知识正式新建与授权检索（P3/N2）**　**Blocked by：T01、T05、T07、T08。** 采用 Inbox 线索时另须 T03 重鉴权，采用已受理团队候选时另须 T27 受理回执和本次创作独立重鉴权（不要求所有创作先受理），采用 AI 提炼候选时另须 T25 的待核结果；用户对获准材料核事实/经验和现有精确版本后明确提交，受控 Git 分支/MR/CI/指定审核人/protected merge 经签名与仓库/路径/actor/commit 校验，Worker 执行 WeKnora ingest，按 document/version/source/path/ACL 读回并实际授权检索后才 `published`。验收：未经确认、关键材料缺失、伪造/旧 SHA/重复事件和未授权路径均不进入正式知识；索引失败/检索不符进 unknown/reconciling，已获授权有效旧版可用而失效旧版先阻断；来源和审核责任可逆查。**外部门**：获准真实非生产 Git/WeKnora 测试空间及最终正负向读回。

**T10｜知识修订、撤权与三方对账（P3/N2）**　**Blocked by：T09。** 对固定 ID/基线版本修订、移动/重命名和受审退役；紧急撤权先阻断受控入口，Worker 以持久游标核 Git/PG/WeKnora 的新旧版本、旧路径及索引。验收：并发旧基线冲突、漏投/乱序/站外 merge、旧 callback、半成功与重启续扫均不推进假成功；声明的入口中旧 document/版本/直连和撤权主体负向检索可复核；目标不支持外部封锁则保持 `withdrawal_unknown/revocation_unknown/manual_required` 和安全升级，不称撤回完成。

**T11｜关联的合成知识真实链与大盘读回（P3/N2）**　**Blocked by：T09、T10、T24。** T24 完成后可先做隔离回归； 相互关联的虚构半导体采购资料和正式知识从入口②经真实非生产审核、Git/Worker/WeKnora 测试空间读回，到入口⑤按资产 ID/版本去重显示项目×产品线、来源与获权具体文档深链；扫描批次仅在 T26 实际巡检后展示；项目 Wiki 内读与真实 AI 巡检分别由 T23/T26 验证。验收：多个来源的冲突、修订、索引失败、撤权、旧版残留、深链过期/越权均显示待核/unknown/拒绝而非绿色；静态预置诊断显式标 `fixture`，无真实扫描批次不称智能诊断，真实非生产链不推断业务价值或生产授权。**外部门**：目标审核/索引/检索/深链存在且按当前身份重新授权读回。T10 是撤权/旧索引反例可验证的前置，不要求每次合成新增都先退役。

**T12｜条目评论驱动 AI 下一版待核稿（P3/N2）**　**Blocked by：T01、T07、T09、T24。** 成员对有权事实/经验条目、来源锚点及固定草稿 revision 留评论；获准非生产模型以固定旧稿、评论、来源锚点和基线生成同一条目的下一版**完整待核稿**，在界面并列差异与引用，供人核事实、重新审阅受影响的内容角色及 Action 候选、决定是否发起正式修订，绝不直接覆盖来源说法或已发布资产。验收：评论独立持久回读，模型回复的任务/回合 ID、成功终态和归属可核；刷新、重复/响应丢失/超时先读回，旧 revision、迟到回复与并发修改用 CAS 拒绝覆盖，撤权与跨空间拒绝；`accepted`/流式片段不算成稿，缺可靠回复终态时仅保留评论与人工修订路径并将 AI 生成项记 `blocked`，不拿 OTel 或静态原型补证。**外部门**：目标模型调用和 comment/turn/reply 可验证契约、授权输入与内容安全准入；不获准就不能将人工改稿视为 T12 完成。

**T13｜知识消费归因与真实场景效果评测（P5/N4 Knowledge 子项）**　**Blocked by：T09、T24。** 反馈依 T04，不依赖 Skill； 有权消费入口分别记录任务/查询/零结果、实际检索与答案实际引用，沿可失效 DSH 任务/Trace 引用按当前身份/空间重验，并按真实知识 ID/version/source commit、WeKnora document/version 归因；用 T24 合成样本回归正常及负例后，再由业务方授权真实场景测试集与真实数据，在目标 DSH 环境逐例对照应召回、实际检索、答案引用及业务适用性，由业务 Owner 人工复核。验收：只检索未引用不算引用；多查询/多文档、重复/迟到、版本漂移、撤权/跨空间与敏感字段拒绝；保存最小事件和引用、不复制完整 Trace/Prompt/Tool 参数。缺可信底账或分母时前端总体率显示“不可计算”，只报告已标记样本；这不是完成标准，缺授权真实场景评测或目标读回则 T13 效果项 `blocked`，不得以合成数据、安装/检索或虚构成功率代替。

**T14｜Skill 候选、测试设计与静态门禁（P4/N3）**　**Blocked by：T01、T24。** 有效 Knowledge 查询路径另需 T09； 用户从团队精确旧版或获准外部候选核来源、版本、任务缺口后进入 Workflow/Skill Draft，固定 `SKILL.md` 指令、manifest、effects、输入输出、依赖与 golden/boundary/exception/regression/security 测试集及人工语义判据；无知识查询的 Skill 不绑定 Knowledge。验收：对确需查询的固定 ID/version 写明零结果、无权/失效的用户核实与停止判断；拒绝 `latest`、无权来源、越权 effects、未确认材料；静态 schema/secret/权限检查不执行脚本或真实 Tool，不冒充目标模型试跑通过。未批准 Skill Draft 不得由普通 DSH 宿主会话发现/调用或经 TeamAI 分发；仅可按 T15 安全门在获准隔离 Runner 中执行，受控审核分支/MR 不等于 canonical 已发布。

- **实际做哪一张**：没有阻塞票的 T01/T02/T04/T05/T08/T24 及独立 Provider Spike 可在 P0 受限过渡下只用隔离脱敏 fake 开始；T03/T06/T12/T14/T22–T28 随各自前置推进。T27 的独立受理不强制成为所有正式创作的前置，T28 不默认阻塞 T21。表中“Blocked by”指进入所写完整演示目标，局部 fake/静态契约不是另一个已通过的真实交付。
- **测试驱动与取证**：确定性功能先固定正反例/失败重试的自动测试再实现；外部接入先契约/fake，后获准非生产实测与读回；AI/Prompt/Skill 先固定输入、预期和人工语义判据，再在获准隔离环境实跑目标模型、修订后重测。知识最终效果另需授权真实场景测试集及真实数据的业务复核。每票记录目标版本/环境/固定 commit、artifact/package/fixture digest、授权范围、执行人与复核人、实际命令/退出码、正向、无权/撤权、重复/乱序/timeout/读回不符、回滚及 evidence manifest digest。按实际仓库脚本和目标能力给出可复制的 format/lint/typecheck、unit、integration、contract、security/secret scan、migration/restore、failure injection、coverage 和目标 read-back 命令；未建立脚本或未获目标授权记 `not_run/blocked`，不补造结果。
- **逐票原型对照与复测门**：每票开工前登记适用的原型版本/页面（无对应界面则写不适用及理由）、固定样本与状态、该票负责的功能正反例及失败路径、预期差异和未接入项；不把整站原型当验收范围。涉及界面的切片另固定用户路径、宽窄面板、信息层级/密度、溢出与独立滚动、焦点及键盘可达性检查点；非 UI 票注明视觉不适用及理由，仍须记录功能差异和修复复测。先核确定性契约，再在实际目标宿主按相同路径点击、滚动并记录文字、布局和可达性；逐项登记预期与实际，把差异标为预期差异、缺陷（含严重度）或未验证，并给出位置/截图、环境和责任票。缺陷修复后用固定样本、同路径和同宽窄条件复测受影响项及相邻回归，记录前后差异和剩余阻断；未复测不勾通过。视觉对照以布局、阅读顺序和可操作性为准，不以 VM 样式断言或像素级相同冒充宿主观察；原型本身也不是授权、解析、发布或业务结果证据。
- **证据分层**：本地静态/单元/VM/contract 只能证明各自确定性条件；隔离宿主安装后的实际点击/截图另证插件在指定包与 profile 的功能和视觉表现；获准真实非生产 Provider/身份/ACL/数据链的逐项正负向读回才证对应集成，授权真实场景效果和业务复核再独立取证。前一层不自动升级后一层，任一未运行记 `not_run`、无授权记 `blocked`。另以合成演示包的 K10 需求与订单版本对照作**独立只读本地文件试读**：只核选取 UTF-8 文件后全文/表格/来源链接文字可读、原文状态不被改写及返回/切换；不把 K10 当周报指纹样本或推断其已自动抽取、获得 K07 全文权限、受理/导入团队资产或证明订单变更。试读也须按上述逐票对照记录实际结果，未跑不报通过。
- **合成测试扩容**：先测完[T24 小样本基线](./合成测试基线/README.md)的相应契约与正负例，再按 P1/P2 权限契约、P3 跨文档 Knowledge 链、P4 Skill 隔离评测、P5/P6 DSH 对话与端到端回归，分阶段使用[产品演示大包](../产品/演示素材/虚构半导体采购/README.md)的 K01–K14、技能矩阵、S01–S03 候选架构和 50 问；每阶段只运行已获准、已具备来源预授权视图与检索前 ACL 的范围，逐题记录实际引用/权限/执行回执。两包不混同事实、时间或身份，演示包不得替代授权真实场景效果评测；具体停测条件见[基线回放口径](./合成测试基线/README.md#后续分阶段产品演示包)。
- **状态与安全**：产品规则已裁决不代表接口、Runner 或 Provider 已验证；fake/admin 仅是契约或限期 fallback，合成输入经真实非生产链只证明**声明范围内的集成**，真实团队数据和业务价值需另外授权验证。no real team-asset writes before trusted identity, ACL, isolation, revocation, and recovery gates; no production credentials, sensitive originals, full Prompts, or sensitive Tool parameters in code, logs, fixtures, bundles, or evidence; no execution of unapproved Skill Drafts outside an approved isolated nonproduction Runner; no promotion of fake/admin or incomplete external read-back to `real_verified`. 完整宿主 Session/Trace 也不复制进控制面或证据；任一到期 fallback、`unknown/reconciling`、撤权读回缺失保留 owner、时限和下一动作，不靠 UI 绿色消除。
