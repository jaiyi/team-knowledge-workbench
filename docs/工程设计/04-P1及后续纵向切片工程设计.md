# P1 及后续：纵向切片工程设计与待确认任务

> 本文件把[现行产品逐页设计](../产品/界面功能设计/README.md)与[方案 08 的唯一实施/验收路线](../方案/08-MVP实施、验证与验收.md)拆为可独立演示的工程任务草案；具体 API、授权/事件与增改退役/三方对账字段以[方案 11 的拟议集成基线](../方案/11-开发工程设计与集成基线.md)为输入，经方案阶段 1 的设计冻结和目标 Spike 后实施。[方案 12 的 R-01–R-09/I-01–I-04](../方案/12-未决工程风险与决策记录.md)仍是产品已裁决、工程待证；这里的任务完成条件不是已有通过证据。任务尚未发布到 tracker。

## 1. 实施编号、事实与门禁

| 本工程阶段 | 方案阶段 | 能力节点（独立验收，不按编号推导完成） | 可演示边界 |
|---|---|---|---|
| P0：既有基础与安装/Provider Spike | 0–2；部分 3 的骨架 | N0 安装子项待证 | 当前 `p0_overall: no_go`、仅 `p0_transition: allowed_with_no_go`；以[03 当前状态](./03-P0当前状态描述.md)为准，不能用本地健康或 HTML 演示解除门禁 |
| P1：隔离 fake contract | 1–3；并行做 2 的 Spike | N0 基础、N1 契约预备 | 私有对象/权限语义与假 Provider 的完整最小操作，无真实团队资产写入 |
| P2：持久控制面与真实写入准入 | 3–4 | N1；N0 安装仍单独验收 | 两个 asset-space 身份、持久 Worker、撤权、恢复和对账负向验证通过后，才允许**受控非生产**真实团队写入 |
| P3：Knowledge-first | 5；阶段 6 的 Knowledge 部分可随后先行 | N2；N4 的 Knowledge 子项 | 材料/来源→候选→正式审核→Git/WeKnora 读回；合成输入经真实非生产链进入大盘 |
| P4：Skill MVP | 7，复用阶段 6 的事件契约 | N3；N4 的 Skill 子项 | 未批准 Draft 只有静态检查；隔离 Runner 准入后试跑；受审 Git 发布、固定包与最小消费分开 |
| P5：消费、反馈与 Tool Demo | 6，可在 P3 后先做 Knowledge，P4 后补 Skill | N4 整体需双资产和真实只读 Tool Demo | 无会话反馈、可信底账与三层结果；无宿主证据不计算总体率 |
| P6：选型后的 Provider 与试点 | 8–9 | N5–N6 | 优先评估 TeamAI 多设备分发；独立 Registry 需求成立才选 SkillHub；逐目标装载与业务试点另验 |
| P7：按需演进 | 9 后另行决策 | 无自动新增节点 | 不把 User-authored Plugin、生产数据或模型治理纳入本批任务 |

这里的 P1–P6 是[工程路线](./00-整体工程开发阶段划分.md)的较细实施切片；[方案 11](../方案/11-开发工程设计与集成基线.md)称「P1 双资产 MVP」是更粗的交付集合，不能把同名数字当同一阶段。阶段 0 的低风险试点场景、受益者、人工基线、业务结果 Owner 和停止条件尚须业务侧确认；合成 fixture 的技术实验不以此为前置，但 Pilot Beta 必须有这些输入。真实团队资产写入前，可信服务端身份/ACL、双空间隔离、撤权、Worker 重启恢复、路径/secret 负向测试和 reconciliation 必须全部通过；没有任何单项 fake 通过可替代整体门禁。

每张任务沿「用户动作／获准服务身份→服务端校验/状态→对应 Provider 或 fake→可返回的 UI/结果/失败→自动测试与证据」给出一个最短完整路径。表中 `Blocked by` 只列**本表的真前置**；`外部门` 属于额外的环境/安全/业务硬条件，不能当已完成任务。并行开发不能绕过前置验收。各项演示使用脱敏合成样本；未获真实非生产授权时只交付明确标注的隔离 fake/contract 结果，不将目标任务勾为真实通过。具体字段不在本文件再造第二套状态字典。

## 2. 待确认 tracer-bullet 任务（不发布）

**T01｜五入口状态与按需会话（P1/N0 契约）**　**Blocked by：无。** 从本地隔离身份打开五个入口，有权的默认「我的工作台」及每入口 `disabled_reason/provider_status` 可读；只读浏览/复用已有准确版不产生会话，明确创作经当前身份、来源、空间和动作校验后才返回唯一 `session_id/draft_id`。验收：同一操作的重复点击幂等；跨空间/撤权/旧基线拒绝且无 Session/Draft；DSH 原生对话不成为第六入口，静态页面不被称真实后端。真实主体集成仍受 T07 门禁。

**T02｜个人 Inbox 私有保存与零副作用（P1/N1 契约）**　**Blocked by：无。** 用户保存、回访、删除获准的最小链接定位/笔记；独立 PG 私有记录可刷新读回，本人同/异空间按权限读取。验收：第二主体/猜 ID/撤权/过期引用拒绝；保存、导航到知识页和删除都没有 HTTP 抓取/解析、团队候选、反馈、Session、Git 或索引操作；不复制受限原文、签名 URL 不泄露。真实用户持久化启用受 T07 与 I-01 门禁；否则只用隔离 fixture。

**T03｜Inbox 明确分享与后续正式创作（P1/N1 契约）**　**Blocked by：T02、T01。** 用户在知识页先看待核定位，选具体内容/来源/用途/目标团队并明确授权，得到独立 `submission_id`；只在其后明确正式新建/修订、服务端重核当前 ACL/基线/动作时才建会话。验收：导航/取消/分享拒绝不建会话，分享已受理仍零 Session/Draft，重复分享同键去重，分享后撤权/跨空间正式创作拒绝且不复制正文；删除个人项不自动撤销独立获准提交。真实受理受 T07 门禁与 I-02 决策；其中独立受理者不依赖 T01 的会话实现，T01 只门控本票末端的正式建会话演示。

**T04｜无会话疑点与反馈受理（P1→P5/N4 Knowledge 子项）**　**Blocked by：无。** 用户即使没有消费事件或正式资产也能报最小疑点并取得状态回执；获权的受理人核验/去重，分流为知识修订、Skill 回归、Provider 问题或平台问题并回访。验收：报告、拒绝、误报关闭、转交均零自动 Session/正式资产变更；仅明确正式修订并经 T01 的重鉴权后关联唯一新会话；撤权、未分派、重复提交和非知识根因有可见处理人或下次检查时间。真实空间启用受 T07 门禁。

**T05｜材料覆盖、锚点与时效阻断（P1→P3/N2）**　**Blocked by：无。** 用材料/知识 owner 冻结的首期格式×大小×语言/版式、关键区块和形成/生效/截止规则，从固定脱敏原件/hash 生成逐页/段/表锚点、已读/未读/排除范围和只读待核结果。验收：逐区块原件对照；损坏、截断、漏页/表/附件、关键锚点缺失、时效不明、未支持的扫描/复杂表格不产生可送审正式候选；获准补证后按固定版本重验，不拿模型置信度补漏。真实上传/解析范围须由目标 parser 正负例和 owner 批准，缺证仅做隔离测试。

**T06｜受限链接抓取与原件定位（P1→P3/N2）**　**Blocked by：T05；与 T02 无前置关系。** 知识入口由用户明确选用链接，当前主体、来源/用途/空间再授权后才临时抓固定原件、解析并提供来源锚点；Inbox 操作不进入本路径。验收：允许列表、每跳跳转/DNS/实际连接目标、文件大小/MIME/内容、解析器隔离/超时的正负例；跨空间、私网/内部地址、恶意/损坏输入拒绝且零外传；只读梳理不自动分享、建会话或留全文。目标来源/安全准入未通过即仅保留最小待核定位；原文阅读优先经授权的指定 WeKnora 来源文档深链或原系统定位，目标不托管时不伪造链接/Workbench 全文阅读器。

**T07｜可信身份、双空间与连接准入（P2/N1）**　**Blocked by：T01（授权语义）；P0 安装门不因本任务自动通过。** 服务端以目标 DSH 身份交换重核成员/角色、团队/asset-space 和仓库/WeKnora 绑定；获权管理员能在站内草拟、检查、激活或停用连接，成员仅见非敏感状态和可执行下一步。验收：两个空间与两台独立 Desktop 的会话/草稿/Inbox/审计隔离，篡改 team/目标/路径、符号链接逃逸、共享凭据、撤权后的旧 session/job/callback 均拒绝；连接检查不是资产已发布，Secret Manager 引用不回显，配置版本冲突/旧配置在途操作有读回。**外部门**：固定目标 DSH 身份与签名/撤权实测、目标凭据/Owner 授权、双空间负向报告；未通过仍不得真实写入。

**T08｜持久操作、Worker 与半成功对账（P2/N1）**　**Blocked by：无（可用脱敏 fake 开发）；真实写入须 T07。** 用户能提交一个受限 fake 操作并在重启 API/Worker 后查询同一 operation 的结果、失败/unknown/人工接管；outbox 与状态同事务，lease/fencing、重试、CAS 和审计可复现。验收：响应丢失、重复/乱序/旧 callback、超时、read-back mismatch、lease 争夺、Worker/PG 恢复不丢任务、不重复外部副作用或把半成功显示绿色；secret/path 负向、两空间 job/outbox 隔离和数据恢复证据齐全。T07 与 T08 **连同外部能力准入**均通过才解除受控真实团队写入阻断。

**T09｜知识正式新建与授权检索（P3/N2）**　**Blocked by：T01、T05、T07、T08。** 用户对获准材料核事实/经验和现有精确版本后明确提交，受控 Git 分支/MR/CI/指定审核人/protected merge 经签名与仓库/路径/actor/commit 校验，Worker 执行 WeKnora ingest，按 document/version/source/path/ACL 读回并实际授权检索后才 `published`。验收：未经确认、关键材料缺失、伪造/旧 SHA/重复事件和未授权路径均不进入正式知识；索引失败/检索不符进 unknown/reconciling，已获授权有效旧版可用而失效旧版先阻断；来源和审核责任可逆查。**外部门**：获准真实非生产 Git/WeKnora 测试空间及最终正负向读回。

**T10｜知识修订、撤权与三方对账（P3/N2）**　**Blocked by：T09。** 对固定 ID/基线版本修订、移动/重命名和受审退役；紧急撤权先阻断受控入口，Worker 以持久游标核 Git/PG/WeKnora 的新旧版本、旧路径及索引。验收：并发旧基线冲突、漏投/乱序/站外 merge、旧 callback、半成功与重启续扫均不推进假成功；声明的入口中旧 document/版本/直连和撤权主体负向检索可复核；目标不支持外部封锁则保持 `withdrawal_unknown/revocation_unknown/manual_required` 和安全升级，不称撤回完成。

**T11｜合成知识真实链的大盘读回（P3/N2）**　**Blocked by：T09、T10。** 一份明确合成资料从入口②经真实非生产审核、Git/Worker/WeKnora 测试空间读回，到入口⑤按资产 ID/版本去重显示项目×产品线、来源/扫描批次与获权具体文档深链。验收：修订、索引失败、撤权、旧版残留、深链过期/越权显示 unknown/拒绝而非绿色；静态预置诊断显式标 `fixture`，无真实扫描批次不称智能诊断，真实非生产链不推断业务价值或生产授权。**外部门**：目标深链存在与重新授权读回。T10 是本票宣称撤权/旧索引反例可验证的前置，不要求每次合成新增都先发生退役。

**T12｜条目评论与人工改稿（P3/N2）**　**Blocked by：T01、T07。** 成员对有权条目和固定草稿修订保存评论，刷新/失败仍能读回并人工提出新待核稿；评论不随 DSH 回复是否可用丢失。验收：跨空间、旧 revision、并发人工改稿、撤权拒绝；`accepted`/流式输出不能自动覆盖草稿。若以后启用 DSH 自动回复，另需目标 comment/turn/reply/终态/刷新读回和 CAS 的独立 Spike：未通过仅保留人工路径，不把 OTel 或静态原型当回合证据。

**T13｜知识消费底账与版本归因（P5/N4 Knowledge 子项）**　**Blocked by：T09；不依赖 Skill。** 有权消费入口分别记录查询/零结果、检索和答案实际引用，按真实知识 ID/version/source commit 与 document 读回关联；反馈可引用精确版并走 T04 的受理。验收：只检索未引用不算引用，任务多查询/多文档、重复/迟到、跨空间、撤权与敏感字段拒绝；宿主可信查询底账或引用证据不足时总体率显示“不可计算”，只报告有标记的观测样本，不从安装/检索推业务成功。

**T14｜Skill 候选核对与静态门禁（P4/N3）**　**Blocked by：T01；有效 Knowledge 查询路径另需 T09。** 用户从团队精确旧版或获准外部候选核来源、版本、任务缺口后才进入 Workflow/Skill Draft，得到 `SKILL.md`/manifest、effects、输入输出和静态 schema/secret/权限/依赖结果；无知识查询的 Skill 不绑定 Knowledge。验收：对确需查询的固定 ID/version 写明零结果、无权/失效的用户核实与停止判断；拒绝 `latest`、无权来源、越权 effects、未确认材料；静态检查不执行脚本或真实 Tool，不显示为 golden 试跑通过。

**T15｜未批准 Skill Draft 的隔离试跑（P4/N3）**　**Blocked by：T14。** 在安全/平台 owner 已准入的隔离非生产 Runner 用获准脱敏 fixture 对指定 revision 实跑 golden/boundary/regression/security，用户可看通过/失败与审计回执。验收：未准入时 API/UI 默认阻断可执行请求；目标的最小权限、网络/文件/进程/跨空间、CPU/内存/时间/并发/成本、超时终止和清理负向验证通过才放行；结果绑定固定 revision/依赖，撤权或超限拒绝送审；普通 Tool 通道与浏览器演练不代替 Runner。**外部门**：Runner 选型、安全审查与目标实验批准；未通过只交付 T14 静态路径。

**T16｜Skill Git 发布与固定包（P4/N3）**　**Blocked by：T14、T15、T07、T08。** 对有合格测试的固定 Skill 草稿创建受控 MR，核 CI/指定审核人/canonical protected main merge 后显示该版本 `已发布`，从固定 merge commit 构建可复现包/digest，并以有期限管理员固定包 fallback 在获准目标安装/读回、回滚；有 Registry 时 release 另走 T19 的选用分支。验收：已批准未 merge、镜像仓 merge、旧 SHA 均保持 `审核中`；未提交工作区/`latest`/包摘要漂移阻断构建或交接；fallback 有 owner、目标、到期、审计与回滚，不使未合并 Skill 发布、不叫 Registry release。**外部门**：目标 DSH 包格式与最小安装/load 契约按固定 profile 验证；fake 装载只记录 fallback，不声明真实 loaded。

**T17｜Skill 最小消费与 N4 双资产收敛（P4/P5，N3/N4）**　**Blocked by：T16、T13、T04。** 固定 Skill version/package digest 的一次获准最小消费和反馈按 invocation 与 attempt 分列、按 technical/contract/business 三层显示；知识反馈保留独立路径。验收：重试只算一个 invocation，迟到/unknown/digest mismatch 进对账，缺宿主可信开始底账不报总体通过率，缺业务结果为 `unknown`；可对照 Knowledge 实际引用和低反馈覆盖，不能由包安装/load 推执行成功。真实 DSH 事件/底账缺契约时仅报告已观测合成测试与不可计算，N4 真实消费项不通过。

**T18｜隔离只读合成 Tool Demo（P1 契约→P5/N4）**　**Blocked by：无（可使用独立获准的隔离非生产测试身份）。** 从「连接业务数据源」按真实测试主体发现 Demo 的目录、详情/schema 与字段/环境权限，受控试参调用获准隔离非生产只读合成目标并返回来源、审计、失败回执；申请意向与提供方批准另列。验收：撤权/无权字段/错误环境/失败响应不得调用或显示成功；真实目标的请求与读回及回滚可复核；无授权目标时仅完成 fake contract 并将真实 Demo 记 `blocked`，不推断生产目录、审批、统计或业务 Tool 可用。**外部门**：真实目标须单独批准测试主体、字段/环境及审计通道；该 Demo 不解除 T07 的团队资产写入门禁。

**T19｜目标分发/Registry 选型与逐目标读回 Spike（P6/N5）**　**Blocked by：T16；可以并行准备选型。** 对是否有多端分发和独立 Registry 需求形成 ADR；优先验证 TeamAI 同仓/经审镜像的固定 commit/包映射、成员首次 init、Hook/主动 pull、逐目标落盘文件/digest/离线撤回，确需独立 Registry 才验 SkillHub/等价 release id/version/digest。验收：未选 Registry 记 `not_selected` 而非失败；仓库可见、发布请求、目标安装、DSH loaded 各自分列；镜像未审、目标漂移、离线旧包/本地修改、撤回未知均阻断该目标成功。**外部门**：目标版本、用户/空间授权、选型与目标端正负向实测；未选 TeamAI/TeamLab 不自动阻断 Skill Git 发布。
