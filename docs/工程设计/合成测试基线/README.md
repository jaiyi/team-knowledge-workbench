# 虚构半导体采购合成测试基线

> 全部组织、人员代号、物料、日期、价格、流程与文档都是虚构测试数据，不代表真实团队事实、生产知识、已发布资产或已执行模型/Provider 的结果。固定样本仅供开发与回归；使用真实业务资料、真实 DSH/WeKnora/Git 或 Pilot 另须逐项授权。禁止把敏感原件、生产凭据、完整 Prompt 或敏感 Tool 参数放进仓库、普通 fixture、日志、包和证据。

## 文件与固定背景

- [来源与证据锚点](./01-虚构来源资料.md)：虚构「星河晶圆设备采购组」项目 `PRJ-ORION-7`；两个隔离空间 `AS-ORION`（项目组）和 `AS-VEGA`（其他团队）；假设评测日 **2026-07-15**。来源 `SRC-REQ-01`、`SRC-QA-02`、`SRC-QUOTE-03`、`SRC-CHANGE-04`、`SRC-REVIEW-05`。锚点格式 `来源ID#段号`，可逐项核原文而不是推测。
- [知识与项目 Wiki](./02-知识修订与项目Wiki.md)：`K-LEAD-01` v1→v2 的待核/受审期望，项目 Wiki `WIKI-ORION-01` 与正式 Git 知识分开，评测日有效/过期判断。文件中的版本是**预期 fixture**，没有发生 Git merge 或 WeKnora 索引。
- [限定能力矩阵与 example Skills](./03-能力矩阵与Skills.md)：仅是该虚构项目的预期测试能力，不是全队能力地图；固定 Skill 草稿、正常/边界/拒绝例和人工语义判据，均非已安装/执行或正式发布。
- [场景与评测判据](./04-场景与预期.md)：知识召回、评论、AI 提炼/巡检、任务反馈与复盘的正常和负例；每个预期均须在目标获准环境另取实际执行读回。

## 回放口径

1. 先锁定样本 ID、锚点、评测日、角色、空间、知识/Skill revision 和预期；变更其中任一项应更新相关场景及人工判据，不能沿用旧模型评测。
2. 确定性逻辑先用 unit/contract/fake 的正常、越权、失效、重复/乱序/回滚例回归；模型先固定输入/预期/禁止行为，经准入 Runner 实跑并由人评价语义。静态示例和人工编写答案都不是模型执行证据。
3. 合成样本经获准真实非生产 Git/WeKnora/DSH 链完整读回，只能证明该目标范围集成；最终知识效果需业务方另行授权的真实场景测试集与真实数据，逐例核应召回、实际检索、答案引用和适用性。缺目标/授权须记 `blocked`，不可推断 `real_verified`。

## 后续分阶段产品演示包

本基线先验证小样本的契约、权限和异常，再按已通过的能力范围使用[产品侧虚构半导体采购演示包](../../产品/演示素材/虚构半导体采购/README.md)做较大规模的跨文档、跨入口回归；两包的项目、角色、日期和预期相互独立，不能混用或把后者代替真实业务场景数据。演示包目前是未执行的测试输入，其 K01–K14、能力矩阵、S01–S03 候选架构与[50 条问答](../../产品/演示素材/虚构半导体采购/DSH原生对话-50问答测试.md)均不是已发布资产或通过记录。

- **P1/P2 隔离回归**：先核本包固定锚点、版本、负例与双空间拒绝；随后用产品包核多角色、跨项目、旧版/请求/承诺区分。未具备检索前 ACL、角色化测试空间和受控来源视图时，产品包的受限材料与越权题只记 `blocked/无法验证`，不能将全部原件全员索引后依赖模型拒答。
- **P3 Knowledge 链与 P4 Skill 门**：获准后逐批导入产品包可见范围内的材料，核覆盖/锚点、人审 Git merge、WeKnora ACL/检索及大盘读回；S01–S03 先按候选架构设计测试，只有隔离 Runner 实跑、受审发布、固定包装载分别取证后才测真实 Skill 调用。需求协调角色所需的去标识来源视图未提供时不得以受限原文代替。
- **P5/P6 DSH 对话与端到端回归**：在相应目标链已就绪时按问答表逐题记主体、固定资料版、实际检索/引用、权限决策、Skill 装载/执行与 Tool 回执，并由人评事实、状态、引用和边界；未具备相应链路的题标 `无法验证`，不抄预期当实测。每次扩展范围保留上一阶段回归及差异/复测记录。

产品包即使在获准非生产目标跑通，也只能证明所测合成情景与集成范围；真实知识效果及业务价值仍须另取授权真实场景、真实数据和业务 Owner 复核。对应任务草案：[T24 及依赖 T11/T13/T15/T25/T26](../04-P1及后续纵向切片工程设计.md)。
