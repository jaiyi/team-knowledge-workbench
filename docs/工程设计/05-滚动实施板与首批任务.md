## 2. 首条执行切片：T24 → T05 → T01（隔离 fake）

选择一条最薄的“固定样本→材料是否足以提炼→明确创作才建会话”的本地契约路径。它不包含模型提炼、Inbox、Git merge、WeKnora 索引、真实身份或正式发布。A1/A2/A3 已完成各自注明的隔离子项，详见对应记录；每卡的完整产品/外部验收仍未完成，开发 owner、实际目标环境和独立复核人仍待指定。

### A1 · T24 固定小基线的可回放契约（先做）

- **输入/范围**：仅 [工程小基线](./合成测试基线/README.md)的 `PRJ-ORION-7`、`AS-ORION`/`AS-VEGA`、2026-07-15、`SRC-*` 锚点、`K-LEAD-01` 待核 v2 和 `CASE-*`；产品 [演示大包](../产品/演示素材/虚构半导体采购/README.md)另有事实与日期，暂不混测。固定样本版本与 digest 后才能记录回放结果。
- **先写测试**：正例逐一校验来源 ID/段锚点/跨文档引用、角色/空间、评测日期与正常/边界/拒绝预期一致；反例改错锚点、把内部目标交期当供应商承诺、把 v2 待核当已发布、跨空间读取时必须失败或标缺证，不产生成功报告。
- **最小交付/退出**：可重复的小基线校验用例和 fixture digest；自动化测试的实际命令、退出码、失败例及复核记录。[本次隔离子项记录](./合成测试基线/05-T24隔离契约测试记录.md)只核五份现有文本的一致性与预期负例，未完成后续真实链回放；独立复核人仍待指定。
- **停止条件**：样本含真实敏感原件/凭据，或来源、时点、授权边界相互冲突而未裁决。仅合成契约通过不称 DSH/Provider/模型成功。

### A2 · T05 材料覆盖、锚点与时效阻断（在 A1 样本锁定后）

- **先写测试**：正例定位关键段、区分 2026-08-31 内部目标与过期报价、识别 R2→R3 与审计/适配缺口；反例漏 `SRC-CHANGE-04#P2`、报价过期、损坏/截断、关键段/表缺失、时效不明或不支持格式时，阻断可送审候选并指出待补证范围；补证须固定新版本再重验。

- **输入/范围**：隔离 fake 身份和空间；展示五入口的 `disabled_reason/provider_status`；在核证结果上选择“只读浏览/取消”或“明确正式创作”两种动作。真实主体集成和启用须待 T07，不以静态 UI 当后端。

## 5. 每次执行的记录与扩容门

每张子项开工时登记 owner/复核人、范围、固定 commit 与 fixture digest、环境及授权、预期正反例和停止条件；执行后才登记实际命令、退出码、测试结果、故障/撤权/重试/读回与证据 digest。fake 契约、获准非生产目标最终读回、授权真实场景/真实数据效果是三层独立证据，不互相替换。确定性逻辑先负/正测试再实现；AI/Prompt/Skill 先锁输入和人工语义判据，获准隔离 Runner/目标模型试跑后重测；最终知识效果逐例核应召回、实际检索、答案引用和适用性。

小基线相应契约与负例验证后，按 P1/P2 权限→P3 Knowledge→P4 Skill→P5/P6 DSH/端到端阶段性扩到[产品演示包](../产品/演示素材/虚构半导体采购/README.md)。角色化测试空间、来源预授权视图和**检索前** ACL 未实现时，受限材料及越权题只标 `blocked/无法验证`，不能靠模型拒答替代资源端拒绝；50 问预期答案不当实跑。获准非生产合成链的通过也不替代业务方授权真实场景和业务 Owner 复核。
