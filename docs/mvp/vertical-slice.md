# MVP Vertical Slice

## Slice 1：Knowledge

1. 接收脱敏资料；
2. 生成候选知识；
3. 贡献者确认事实和来源；
4. 生成 `team-ai-assets` 变更；
5. 通过 schema/secret/link 门禁；
6. 人工审核；
7. fake WeKnora 索引和带来源检索；
8. 记录运行和反馈。

## Slice 2：Skill

1. 接收低风险任务需求；
2. 生成 Skill 草稿；
3. 校验 input/output、知识依赖、effects 和 profile；
4. 执行 golden/regression；
5. 审核并固定 digest；
6. fake DSH 非生产装载；
7. 回放运行；
8. 反馈分流到知识或 Skill 任务。
