## 谁负责什么

| 虚构角色 | 演练职责 | 可建议但不可代替的动作 |
|---|---|---|
| 黎岚｜采购负责人 | 组织升级、审核内部方案并提请有权人决策 | 不能凭聊天记录批准订单或对外承诺 |
| 沈序｜需求协调 | 记录客户需求版本、核对订单证据 | 客户请求并不自动变更接受数量/日期 |
| 邵简｜供给计划 | 对接虚构晶圆/封测资源，提出区间方案 | 口头产能不等于锁定产能 |
| 林澈｜质量接口 | 隔离批次、记录判定与放行证据 | 未判定前不得通过计划表释放物料 |
| 吴衡｜客户协调 | 草拟回复、校对收件范围 | 邮件草稿不等于已发送或形成承诺 |

## 演练权限与决策边界

K03 联系人、K07 完整邮件及 K08 含收件人的未发草稿只授予模拟“客户协调＋负责人”完整访问；需求协调可看脱敏需求摘要或 K10 的按权版本。摘要须由受控资源服务在检索/传给模型前核主体、项目、对象和目的并产生最小化视图；本包没有该服务或独立摘要资产，不能以 K10 可读为由直接读取 K07 原件。质量接口看 K12 待判细节；其他角色只在获授权状态视图存在时看“质量待核”。周报 K14 只列状态及风险，不复制 K03 的地址。真实实施时由服务端以**用户、角色、项目、对象和目的**核验，不靠本文文字或文件名实现权限；跨职能引用须显示获授权视图与来源 ID。发信、下单、释放批次、确认替代料及向客户承诺交期必须走各自业务侧授权/审批与回执。本包没有实现任何审批或正式角色账号。
