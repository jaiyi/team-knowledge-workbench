# S02｜交期偏移与供需方案比较（候选 Skill 架构）

> **DEMO｜纯虚构｜非生产｜设计草案 V1** · 对应[技能矩阵 C04](../团队技能矩阵.md)。仅设计“证据分层＋条件比较”，不是已发布 Skill 或交期批准能力；无实际产能/库存 Tool。索引：[演示包](../README.md)。

## 触发、输入与角色

用户请计划团队比较 PX-A 的提前交付选项，或问“500＋300 是否凑齐 800？”时触发。须由有项目读取权的模拟计划/采购角色调用，且逐来源检查对象/目的授权：[K07 邮件原文](../知识/07-客户需求变更邮件.md)仅客户协调和负责人可读，其他有权项目角色只用 [K10 版本表](../知识/10-需求与订单版本对照.md)或受控服务提供的按权请求摘要；质量详情只有质量角色或特定授权才可读取，其他人只见按权可见的“质量待判”状态。禁止自动修改排程、占用 PX-B 资源、确认替代料、向客户承诺或调用付款/下单接口。

```yaml
project_id: PX-A
requested_qty: 800
requested_window: 2026-11-13
as_of: 2026-10-28
scope: compare-only
source_ids_required: [K06, K11]
source_ids_request_one_of: [K10, K07]
source_ids_conditional: [K04, K12, K13]
request_evidence: <K10 按权版本或经授权 K07 原文/受控摘要；K07 原文仅客户协调/负责人>
identity_and_acl: <宿主/资源端提供，不取模型填值>
```

必要依赖：[K06 条件排程](../知识/06-交期异常专题会纪要.md)、[K11 五个口径](../知识/11-交期产能推演.md)和获准的**当前请求视图**（一般角色用 [K10](../知识/10-需求与订单版本对照.md) 的按权版本或受控服务摘要；完整 [K07](../知识/07-客户需求变更邮件.md)仅客户协调/负责人可用）。条件来源：[K12 质量待判](../知识/12-质量异常与批次隔离.md)按权仅取状态或核验详情、[K13 替代料未批准](../知识/13-备选料验证记录.md)只在讨论替代选项时读取、[K04 供应边界](../知识/04-供应协作方与能力边界.md)在解释产能来源时读取。K12/K13/K04 不可访问时，不填补对应分支的事实，列出缺证；缺 K06、K11 或获准请求视图时停止数量与方案比较，输出 `needs_verification`，而不是仍将 500 当锁量。上线须在 `dependencies.lock` 中锁定实际使用的知识 ID/版本/哈希与摘要逻辑版本（如有），动态业务回执单列只读能力；本演练只有静态 V1，未取得锁或业务有效性回执。

## 流程与判断分支

1. 可信宿主/资源端在检索并传给模型前核权限、目的、逐来源版本及请求视图；K07 原文和 K12 细节均不得先检索再遮盖。K06/K11 或获准请求视图缺失、失效，或资料冲突/跨项目混用时停止比较并请求人核实。
2. 仅在已获准的 K06/K11/请求视图支持时单独列出客户请求量 800、讨论的条件排程 500、**算术缺口** 300、质量可放行量未知、无已记录提前交期承诺；`800 - 500 = 300` 只描述未获确认的部分，**不是另 300 件已排产**。若 K12 无权读取，不查询内部批次详情；只在独立获授权状态视图存在时返回“质量待核”，否则列出质量证据缺失，不能凭原文内容推断。
3. 可选接入只读排程、批次状态、订单回执 Tool（均**待评估接入**）；服务端核对使用人及对象权限，返回来源 ID/时间/状态。不可用或未锁量时保留“未知”，不能用新闻或未经批准的 K13 补量。
4. 输出方案 A：继续核证不调整承诺；B：调查部分交付可能性（需锁量、质量放行、客户接受）；C：升级调整客户窗口。比较每项已知证据、缺口、依赖责任人，**不自动选择最优并执行**。
5. 提交邵简/林澈及黎岚分别审查资源、质量及对外路径；若任何必需证据缺失则止于待核建议，发信/下单/批次释放工具不在允许集合内。

**输出契约草案**：`status`（`ready / needs_verification / denied / failed`）、`request_version`、`requested_qty`、`conditional_schedulable_qty`、`unconfirmed_gap_qty`、`quality_releasable_qty: unknown`、`accepted_commitment: none_recorded`、`source_refs`（实际可见的 ID/版本/视图）、`options[]`（每项 `preconditions`、`evidence_ids`、`unknowns`、`review_owner`）、`stop_reasons`、`no_side_effects: true`。`none_recorded` 仅指本演练**无获证的提前承诺记录**，不以“承诺量 0”推断实际供应能力等于零；缺少来源或权限时仅填可证实字段。
